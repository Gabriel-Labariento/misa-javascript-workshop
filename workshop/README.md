# Your game files

Use the [workshop guide source](../web/src/content/docs/) for explanations and copyable code until the website URL is added.

After cloning, start your own branch:

```bash
git checkout 00-start
git checkout -b my-game
```

Open this `workshop` folder in VS Code. Right-click `index.html` and choose **Show Preview** (from the Live Preview extension), then open the same address in your browser so you can use its console. Opening `index.html` by double-clicking works for Parts 1 and 2, but the modules in Part 3 need Live Preview's local server.
