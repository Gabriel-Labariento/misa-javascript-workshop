The final project is yours. It's fully free: there's no required topic, no restrictions, and nothing stopping your imagination. If there's something you've wanted to build, build it.

You work on it on your own after Workshop 2, and it's due early next semester.

## What we'd love to see

None of these are required, but they're worth aiming for. Each one is something you'll have learned by then.

- Use **Next.js, React, and Tailwind**, the tools from Workshop 2.
- **Deploy it**, so anyone can open your project with a link.
- Use **Git properly**, with clear commits, branches, and pull requests.

## Using AI

You can use AI tools as much as you need. Just make sure you understand what they write, and stay in the loop on every change. It's your project, so you should be able to explain how it works.

## Have fun

This matters most. Pick something you'll enjoy building, and enjoy building it.
