Your mentors will pick one of these games for your team. Both run in the browser, so there's nothing to install.

- [Flexbox Froggy](https://flexboxfroggy.com/): write flexbox CSS to get each frog onto its lily pad. It practices everything from the [flexbox page](../flexbox/).
- [Grid Garden](https://cssgridgarden.com/): write grid CSS to water your carrot garden. It practices the [grid page](../grid/).

Each level asks for a line or two of CSS. If your team gets stuck, open the page for that topic and look for the property the level is asking about.
