Before you can share anything, you need a GitHub account, and a way to use Git on your laptop. We'll use GitHub Desktop during the workshop because it shows every step on screen, with no commands to type.

If you already have both, skip ahead to [everyday actions](../actions/).

## Create your account

1. Go to [github.com/signup](https://github.com/signup) and create a free account.
2. Pick a username you'd be happy to show people. It appears on everything you share, and it becomes part of your profile link.
3. Check your email and confirm your account.

## Sign in to GitHub Desktop

1. Install GitHub Desktop if you haven't yet. The [setup page](../../setup/) has the command for your computer.
2. Open GitHub Desktop and choose **Sign in to GitHub.com**. Your browser opens so you can sign in and approve it.
3. When it asks, enter the name and email to attach to your commits.

If you skipped the sign-in screen, you can find it later under **File → Options → Accounts** on Windows, or **GitHub Desktop → Settings → Accounts** on macOS.

## Keep your email private

Every commit records an email address, and anyone who can see the project can see it. To keep your real email private, GitHub gives you a private commit email. Find it in your [GitHub email settings](https://github.com/settings/emails), and use that one in GitHub Desktop.
