title: Class Wall
description: A team Git relay where everyone adds a profile card to one shared site.
---

Class Wall is one shared repository, published with GitHub Pages. Everyone adds their own profile card to it, using the steps from [one change, start to finish](../workflow/): branch, commit, push, then a pull request and a merge.

## Instructions

The step-by-step instructions are in the Class Wall repository's README. Open it and start from the top.

- [Class Wall repository](https://github.com/Gabriel-Labariento/misa-devpool-class-wall)
- [The live wall](https://gabriel-labariento.github.io/misa-devpool-class-wall/), where your card shows up once your pull request is merged
