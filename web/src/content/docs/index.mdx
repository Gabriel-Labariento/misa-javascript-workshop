This workshop takes you from your first web page to a full web app you build yourself. You don't need any coding experience. Many of you are just starting out, and every lesson is written with that in mind.

## How the series runs

Some parts happen live with mentors, and some you do on your own time. They come in this order:

| When | What you learn | How |
| --- | --- | --- |
| Before Workshop 1 | JavaScript | On your own |
| Workshop 1 | HTML, CSS, and Git | Live, with mentors |
| Between workshops | Tailwind, while you keep going with JavaScript | On your own |
| Workshop 2 | React, Next.js, and Tailwind | Live, with mentors |
| Early next semester | Your [final project](./final-project/) | On your own |

The sidebar lists the modules in learning order, which is a little different. JavaScript comes after Tailwind there, because React and Next.js build on it. The JavaScript module is long, though, so you get it first and work through it alongside everything else.

## How the modules connect

Each module adds one layer to what you can build.

HTML gives a page its content, and CSS makes that content look the way you want. Git saves your work and lets you share it with your team. Tailwind gives you a quicker way to write CSS, right inside your HTML.

JavaScript makes a page respond when people click and type. React and Next.js then help you build bigger apps out of those same pieces. The final project is where you put all of it together.

## How each lesson works

Most pages explain one idea at a time, with small examples you can run right on the page:

- **▶ Run** runs the example. Change anything, run it again, and see what happens. **Reset** brings the original back.
- **Predict** boxes show some code and ask what it will do before you find out.
- **Practice** boxes give you a short task with automatic checks. If you get stuck, open a hint or peek at one possible solution.

Mentors may skip a section during a live session to save time. Every section still makes sense on its own, so you can come back and read it later.
