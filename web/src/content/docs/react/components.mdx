A **component** is a JavaScript function that returns a piece of the page.

```jsx title="components/Greeting.js"
export default function Greeting() {
  return <h1>Hello, MISA!</h1>;
}
```

That's a whole component. The HTML-looking part after `return` is called **JSX**.

## Use it like a tag

Once a component exists, you use it the same way you'd use `<h1>` or `<img>`, as a tag:

```jsx title="app/page.js"
import Greeting from "@/components/Greeting";

export default function HomePage() {
  return (
    <section>
      <Greeting />
      <Greeting />
      <p>Welcome to my site.</p>
    </section>
  );
}
```

This shows the greeting twice, then the paragraph. A page is itself a component, built out of smaller ones. A real site is components all the way down: a page holds a nav, cards, and a footer, and a card might hold a button.

Two rules keep this working:

- **Component names start with a capital letter.** That's how React tells `<Greeting />`, your component, apart from `<p>`, a normal HTML tag.
- **Self-closing tags need a slash.** `<Greeting />` and `<img />` both need the `/` before `>`.

## JSX is almost HTML

You saw this at the end of the [forms lesson](../../html/forms/#from-html-to-react). Here are the differences again, since you'll hit them constantly:

| In HTML | In JSX | Why |
| --- | --- | --- |
| `class="card"` | `className="card"` | `class` already means something in JavaScript |
| `for="name"` | `htmlFor="name"` | Same reason, for `for` |
| `<img src="a.png">` | `<img src="a.png" />` | Every tag must be closed |
| `onclick="..."` | `onClick={...}` | Event names are in camelCase |

There's one more rule that trips people up: **a component returns one parent element.** If you want two things side by side, wrap them in something, such as a `<section>` or a `<div>`.

## Curly braces mean JavaScript

Inside JSX, anything between `{` and `}` is JavaScript. React works it out and puts the result on the page:

```jsx
export default function Today() {
  const name = "Niles";
  const year = 2026;

  return (
    <p>
      Hi, {name}! Next year is {year + 1}.
    </p>
  );
}
```

This shows **Hi, Niles! Next year is 2027.** It's the same idea as `${name}` in a template literal, from [Say hello](../../javascript/hello/).
